# 🧠 Image Classification using Artificial Neural Network (ANN)

This project implements an **Artificial Neural Network (ANN)** using TensorFlow and Keras to classify images. The model is trained and evaluated in a Jupyter Notebook.

---

## 📁 Project Structure
├── ann.ipynb # Notebook with ANN implementation
├── README.md # Project documentation
└── requirements.txt # Python dependencies


---

## 🚀 Features

- Implements a fully connected feedforward ANN
- Uses TensorFlow/Keras for training
- Visualizes training with accuracy/loss graphs
- Supports dataset evaluation and predictions

---

